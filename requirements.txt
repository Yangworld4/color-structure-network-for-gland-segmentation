当前项目是 **两个 UNet 的半监督 CPS，GLaS/CRAG 2D segmentation**。在现有代码上移植论文：

**Conflict-aware Semi-supervised Mutual Learning for Medical Image Segmentation (CSSML, ESWA 2026)**

的两个模块：

1. **CDFL — Conflict-aware Distinct Feature Learning**
2. **GMPS — Geometry-aware Mutual Pseudo Supervision**

目标不是重写训练框架，而是最小改动适配当前两个 UNet CPS。

目标源码在：/data/mission/models/Exp/RefSSL/CSSML
不要 smoke test，不要运行完整训练。

# 1. UNet 返回 decoder feature

CDFL 和 GMPS 都需要 feature。

修改 UNet，使其支持：

```python
logits, feature = model(x, return_features=True)
```

feature 使用：

**最后一个 decoder block 输出、segmentation classifier 前的 feature map。**

例如：

```text
decoder_last
    ↓
feature [B,Cf,H,W]
    ↓
1x1 conv
    ↓
logits [B,C,H,W]
```

默认：

```python
model(x)
```

行为不能改变。

只有需要 CDFL/GMPS 时：

```python
logits, feature = model(x, return_features=True)
```

禁止 duplicated forward。

如果两个 UNet feature channel 数量不同，CDFL 前使用轻量的 1×1 projection 对齐 channel；如果当前两个 UNet完全相同，则不要增加 projection。

# 2. CDFL — 严格按照 CSSML 官方实现

CDFL 同时作用在：

```text
labeled features
unlabeled features
```

设：

```python
feat_a_l
feat_b_l

feat_a_u
feat_b_u
```

官方实现使用：

```python
cos = nn.CosineSimilarity(dim=1, eps=1e-6)
```

## labeled CDFL

```python
loss_cdfl_l_a2b = 1.0 + cos(
    feat_a_l.detach(),
    feat_b_l
).mean()

loss_cdfl_l_b2a = 1.0 + cos(
    feat_b_l.detach(),
    feat_a_l
).mean()

loss_cdfl_l = 0.5 * (
    loss_cdfl_l_a2b +
    loss_cdfl_l_b2a
)
```

## unlabeled CDFL

```python
loss_cdfl_u_a2b = 1.0 + cos(
    feat_a_u.detach(),
    feat_b_u
).mean()

loss_cdfl_u_b2a = 1.0 + cos(
    feat_b_u.detach(),
    feat_a_u
).mean()

loss_cdfl_u = 0.5 * (
    loss_cdfl_u_a2b +
    loss_cdfl_u_b2a
)
```

最终：

```python
loss_cdfl = loss_cdfl_l + loss_cdfl_u
```

这里 **1 + cosine** 是故意的，不要改成 `1 - cosine`。

最小化：

$$
1+\cos(F_A,F_B)
$$

就是降低 feature coupling、保持两个 branch distinct。

不要去掉 `.detach()`。

# 5. GMPS 必须保持的论文逻辑

不论接口如何重构，必须明确划分：

```python
prob_a = torch.softmax(logits_a, dim=1)
prob_b = torch.softmax(logits_b, dim=1)

conf_a, pseudo_a = prob_a.max(dim=1)
conf_b, pseudo_b = prob_b.max(dim=1)

same_mask = pseudo_a == pseudo_b
conflict_mask = pseudo_a != pseudo_b
```

即：

$$
M_{same}=[\hat Y_A=\hat Y_B]
$$

$$
M_{conflict}=[\hat Y_A\neq\hat Y_B]
$$

---

# 6. Same pseudo-label region

论文明确：

如果：

$$
\hat Y_A(i)=\hat Y_B(i)
$$

则这个位置属于 identical pseudo-label。

比较两个 subnet 对共同预测类别的概率：

```python
class_id = pseudo_a  # same as pseudo_b

p_same_a = prob_a.gather(1, class_id.unsqueeze(1)).squeeze(1)
p_same_b = prob_b.gather(1, class_id.unsqueeze(1)).squeeze(1)
```

如果：

```python
p_same_a > p_same_b
```

则：

```text
A → B
```

否则：

```text
B → A
```

只让 probability 更高的一方作为该 pixel teacher。

pseudo-label 和 selection mask 全部 detach。

不要对 same pixel 做双向 CPS。

---

# 7. Conflict pseudo-label region

如果：

```python
pseudo_a != pseudo_b
```

即：

$$
M_{conflict}=1
$$

不要直接用：

```text
lower entropy
higher max probability
prototype reliability
```

选 teacher。

必须使用论文 GMPS 的 **geometry-aware reliability**。

### 严格要求

如果已经找到官方 `compute_gmps_consistency`：

**逐行移植该 geometry reliability 逻辑。**

只允许做以下工程适配：

* tensor shape
* binary/multiclass
* device
* feature channel
* interpolation
* function naming

不得改变：

* geometry score 定义
* conflict selection rule
* epoch-dependent schedule
* loss formulation

---

# 8. 如果官方 GMPS helper 在可访问源码中确实缺失

不要自行发明“近似 GMPS”。

不要用：

```text
entropy
prototype
local majority vote
distance transform
connected component
```

替换它。

这种情况下：

1. 完成 CDFL；
2. 完成 GMPS 的 same/conflict routing 框架；
3. 将 conflict geometry 部分封装成：

```python
compute_geometry_reliability(...)
```

4. 明确留下：

```python
raise NotImplementedError(
    "Exact CSSML GMPS geometry formula is unavailable in the supplied/reference source."
)
```

5. 最终报告中明确指出缺失的是哪一段官方算法。

**绝对不要为了让代码“能跑”而猜一个 geometry score。**

# 11. CDFL + GMPS 总损失

当前两个 UNet：

$$

=
L_{sup}^A+L_{sup}^B
$$

$$
L=
L_{sup}
+
\lambda_{gmps}L_{GMPS}
+
\lambda_{cdfl}L_{CDFL}
$$

实现：

```python
loss_total = (
    loss_sup
    + lambda_gmps * loss_gmps
    + lambda_cdfl * loss_cdfl
)
```

如果当前项目已有 unsupervised ramp-up：

```python
current_unsup_weight
```

则 GMPS 沿用当前 CPS 的 unsupervised weighting/ramp-up，不额外创造第二套 ramp。

不要修改当前 supervised loss。

# 14. GT routing diagnostic

只在 labeled/validation data 上使用 GT 做诊断。

**GT 绝不能参与 unlabeled GMPS routing。**

重点统计 conflict region。

因为 GLaS 是 binary segmentation：

$$
A\neq B
$$

时一定一个正确、一个错误。

因此记录：

```text
conflict_pixels_gt

gmps_conflict_teacher_correct_pixels
gmps_conflict_teacher_wrong_pixels

gmps_conflict_selector_accuracy
gmps_conflict_harmful_ratio
```

定义：

```python
gmps_conflict_selector_accuracy =
    correct_teacher_conflict_pixels /
    all_conflict_pixels
```

这是最重要指标。

后续直接与之前 Relative Entropy 的约 61% selector accuracy 比较。
